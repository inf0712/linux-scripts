## 3. Practical Learning Approach

My learning approach focuses on understanding concepts and applying them through practical exercises.

1. Understand the purpose of a technology.
2. Learn its architecture and important components.
3. Practise commands and configurations.
4. Troubleshoot errors independently.
5. Automate repetitive tasks.
6. Integrate technologies into larger projects.
7. Document implementation, challenges, and solutions.

## 6. Progress Philosophy

Learning a command is not the same as understanding a system.

I aim to understand:
- What a command does.
- Why it is required.
- How system components communicate.
- What happens when something fails.
- How to identify and resolve the failure.
- How to automate the process.

**The objective is not just to learn DevOps tools, but to understand, operate, troubleshoot, and automate the systems behind them.**
